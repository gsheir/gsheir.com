# General instructions

Do not make code changes unless explicitly asked. Just make proposals to start off and ask for user confirmation before making changes.

If you are unclear on the requirements, clarify those before proposing solutions.

Do not suggest code snippets unless asked.

Read the full codebase before making any proposals or changes.

This project uses `uv` for dependency management. Use `uv add` to add any dependencies. Use `uv run` to run any Python. 

This project uses Ruff for formatting. After making changes, use `uv run ruff format; uv run ruff check --fix; uv run ruff check --select I --fix` to format, and address any errors before finishing.

Do not create additional markdown files to report progress or as a summary. Display these in the chat window instead.

If using logging, be concise rather than verbose. Do not use excessive formatting with dividers; newlines are sufficient.

Add only neccesary comments. Do not use excessive formatting with dividers; newlines are sufficient.
